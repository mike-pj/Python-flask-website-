Understand the important SQL statement
UPDATE assignments
SET title = ?, due_date = ?, status = ?
WHERE id = ?

- UPDATE assignments — modify a record in the assignments table.
- SET — specify the new values.
- WHERE id = ? — change only the record with the matching ID.
Why is WHERE id = ? so important?
Without the WHERE condition, an update could change every assignment in the table. The ID ensures we target the intended record.
The question-mark placeholders also help protect against SQL injection.

Add a delete route to app.py:
-Open app.py and add this route below your edit route, but above if __name__ == "__main__":.

@app.route("/assignments/<int:assignment_id>/delete",
           methods=["POST"])
def delete_assignment(assignment_id):

    connection = get_db_connection()

    assignment = connection.execute(
        "SELECT id FROM assignments WHERE id = ?",
        (assignment_id,)
    ).fetchone()

    if assignment is None:
        connection.close()
        return "Assignment not found", 404

    connection.execute(
        "DELETE FROM assignments WHERE id = ?",
        (assignment_id,)
    )

    connection.commit()
    connection.close()

    return redirect(url_for("assignments"))


Understand the important parts
@app.route(...) defines the URL that handles a deletion request.
methods=["POST"] means the route accepts POST requests. We use POST instead of a simple link with GET because deleting a record changes data.

"DELETE FROM assignments WHERE id = ?":
-This SQL statement removes the record matching the supplied assignment ID.
The ? placeholder safely passes the ID into the query.

return redirect(url_for("assignments")):
-After deleting the assignment, Flask sends the user back to the assignments list.
